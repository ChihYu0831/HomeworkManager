# HomeworkManager

## 專案簡介

本專案是一個學生作業管理系統，主要提供作業新增、修改、刪除、完成標記、截止日期提醒、統計分析與行事曆功能。使用者可以透過左側選單切換不同頁面，統一管理各科目的作業資料。

系統首頁會自動顯示今日到期與七天內即將到期的作業清單，並以完成率進度條與統計資料呈現整體作業狀況，讓使用者一眼掌握當前進度。

作業清單會以不同顏色區分作業狀態，包含已完成、今天到期、即將到期與已逾期。

本專案另外加入行事曆頁面與統計分析頁面，行事曆可透過月曆點選日期查看當天到期的作業，統計分析則以圓餅圖與長條圖呈現完成率與各科目作業數量，提升使用者對作業進度的掌握能力。

系統提供設定頁面，使用者可一鍵切換深色與淺色介面主題，也可將作業資料匯出為 CSV 檔案方便在 Excel 中查看，或將 JSON 資料備份至指定位置以防資料遺失。若需要清除所有資料，系統會在執行前再次確認，避免誤刪。

---

## 功能特色

1. 顯示今日到期、七天內到期的作業清單與整體完成率。
2. 作業清單以顏色區分已完成、今天到期、即將到期與已逾期。
3. 支援新增、修改、刪除作業功能。
4. 標記完成後會播放提示音效。
5. 支援關鍵字搜尋，可依課程名稱或作業標題篩選。
6. 行事曆頁面可點選日期查看當天到期的作業，有作業的日期以粗體顯示。
7. 統計分析頁面提供圓餅圖（完成率）與長條圖（各科目作業數量）。
8. 支援深色 / 淺色模式切換，一鍵立即生效。
9. 可將作業資料匯出為 CSV 檔案，或備份 JSON 資料至指定位置。
10. 防呆設計：已完成或已逾期的作業無法再標記完成。

## 執行說明

### 啟動程式

1. 解壓縮專案資料夾。
2. 雙擊開啟 `HomeworkManager.sln`（需安裝 Visual Studio 2022）。
3. 按下 `F5` 或點選「開始」執行程式。

### 新增作業

1. 點選左側選單的【作業管理】。
2. 在上方輸入區選擇課程名稱、填寫作業標題、截止日期與作業內容。
3. 選擇作業狀態（未完成 / 已完成）。
4. 按下綠色【➕ 新增】按鈕，作業會出現在下方清單。

### 修改作業

1. 在作業清單中點選要修改的作業（該列變為藍色選取狀態）。
2. 上方輸入區會自動填入該筆作業的資料。
3. 修改完成後按下藍色【✏️ 修改】按鈕儲存。

### 刪除作業

1. 在作業清單中點選要刪除的作業。
2. 按下紅色【🗑️ 刪除】按鈕。
3. 確認視窗出現後按「是」完成刪除。

### 標記完成

1. 在作業清單中點選未完成的作業。
2. 按下紫色【✅ 標記完成】按鈕，系統會播放提示音並更新狀態。
3. 注意：已完成或已逾期的作業無法再標記完成。

### 搜尋作業

1. 在搜尋欄中輸入課程名稱或作業標題的關鍵字。
2. 按下【搜尋】按鈕或按 `Enter` 鍵進行篩選。
3. 按下【顯示全部】可清除搜尋條件回到完整清單。

### 行事曆

1. 點選左側選單的【行事曆】。
2. 月曆上有作業到期的日期會以粗體顯示。
3. 點選任一日期後，右側會列出當天所有到期的作業。

### 統計分析

1. 點選左側選單的【統計分析】。
2. 左側圓餅圖顯示已完成與未完成的比例及整體完成率。
3. 右側長條圖顯示各科目的作業總數與已完成數量。

### 設定

1. 點選左側選單的【設定】。
2. 可切換深色 / 淺色介面主題。
3. 可將所有作業資料匯出為 CSV 檔案（可用 Excel 開啟）。
4. 可將 JSON 資料檔備份至指定位置。
5. 可清除所有作業資料（執行前會再次確認）。

## 顏色說明

| 顏色 | 代表狀態 |
|------|---------|
| 🟩 淡綠色 | 已完成 |
| 🟨 淡黃色 | 今天到期 |
| 🟧 淡橘色 | 3 天內即將到期 |
| 🟥 淡紅色 | 已逾期 |
| ⬜ 白色 | 一般（4 天以上） |
